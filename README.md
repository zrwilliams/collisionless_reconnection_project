# collisionless_reconnection_project
Code corresponding to Stolnicki and Williams, Physics of Plasmas 2024 paper on eigenmode analyses as applied to electron-inerta-driven reconnection 
Data_generating_scripts contains the python code needed to produce the nonlinear (IVP) and linear (EVP) data analyzed for the paper
Post_processing_scripts contains all the analysis code needed to produce the results and figures shown in the PoP 2024 paper
